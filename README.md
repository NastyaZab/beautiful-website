# Портфолио продуктового дизайнера

Адаптивный одностраничный сайт на HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

## Запуск

Откройте `index.html` в браузере или запустите в папке проекта:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Персонализация

- Замените `assets/portrait.jpg` своей фотографией (рекомендуемый размер от 1000 × 1250), обновите `alt` и подпись в `index.html`. Сейчас используется демонстрационное фото с Unsplash: https://unsplash.com/photos/6W4F62sN_yI, источник файла: https://images.unsplash.com/photo-1534528741775-53994a69daeb. Это не фотография владельца портфолио.
- Тексты «Обо мне», навыков и процесса — редактируемый черновик, а не подтверждённая биография. Замените их при необходимости в `index.html`.
- Названия и обложки проектов — декоративные заглушки, не реальные кейсы.
- Добавьте ссылки проектов, email и Telegram в объект `portfolio` в `script.js`. Пока поля пустые, ссылки недоступны и не ведут на случайные адреса. После добавления адреса проекта его отметка «Скоро здесь» скроется.
- Основные цвета находятся в начале `styles.css`. Шрифты загружаются из Google Fonts; при отсутствии сети используются системные аналоги.

## Публикация

Сайт совместим с GitHub Pages и любым статическим хостингом. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → основная ветка → `/ (root)` → Save.
